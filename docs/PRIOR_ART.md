## Closest competitors

- **RaceDB (2025)**: the closest in goal, finding request races in DB-backed web apps and confirming them with replay. **Deadheat's difference:** it's a developer tool, not a research prototype. It's Node/TS and Postgres-first, driven by user-written business invariants, runs in CI, and controls interleavings actively through a wire-protocol proxy instead of relying on analysis.
- **ACIDRain (2017)**: the same class of bug, found through offline log analysis. **Difference:** Deadheat runs the actual concurrent requests, forces the dangerous interleaving, and gives a replayable repro, so there's no gap between "possible anomaly" and "proven bug".
- **ResilienceCheck / race-the-web**: the closest in workflow (concurrent requests and CI). **Difference:** both depend on luck. Deadheat adds synchronized release, a DB proxy that widens and reorders race windows, shrinking, and seeded replay. race-the-web has been inactive since 2022.

## Gap statement

> Today, developers catch race conditions by writing ad-hoc `Promise.all` load scripts, by running manual security tools such as Burp Suite, or by waiting for a production incident. That fails because unsynchronized bursts rarely hit the tiny race window, the manual tools aren't part of CI, and the research tools that systematically find these bugs (ACIDRain, RaceDB, IsoDiff) never became something a normal backend developer can install.

## Verdict

**The workflow gap still holds, but it's narrower than the playbook assumed.** Academia has attacked this exact problem (ACIDRain, ReqRace, IsoDiff, RaceDB), so don't claim that nobody has done this. Frame Deadheat as **"bringing research-grade race detection into a Node/TS developer's CI"**, and cite these papers in DESIGN.md as prior work you build on.

The sharpest angle combines three things none of the tools above offer together: **invariant-based scenarios, active query-interleaving control through a Postgres proxy, and seeded replay in CI.**

Unverified: whether RaceDB's source code is released, and the exact bug counts in ReqRace.
